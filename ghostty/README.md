# Ghostty Configuration

A Ghostty terminal configuration with keybindings matching Wezterm, Hack Nerd Font Mono, and dark theme support.

## Keybindings

### Tab Operations
| Keybinding | Action |
| :--- | :--- |
| `Alt+t` | New tab |
| `Alt+b` | Previous tab |
| `Alt+n` | Next tab |
| `Alt+Shift+b` | Move tab left |
| `Alt+Shift+n` | Move tab right |

### Pane (Split) Operations
| Keybinding | Action |
| :--- | :--- |
| `Ctrl+h` | Split left |
| `Ctrl+v` | Split down |
| `Ctrl+b` | Previous pane |
| `Ctrl+n` | Next pane |
| `Ctrl+q` | Close pane |
| `Ctrl+Shift+h` | Resize pane left |
| `Ctrl+Shift+l` | Resize pane right |
| `Ctrl+Shift+k` | Resize pane up |
| `Ctrl+Shift+j` | Resize pane down |

### Clipboard
| Keybinding | Action |
| :--- | :--- |
| `Ctrl+Shift+c` | Copy to clipboard |
| `Ctrl+Shift+v` | Paste from clipboard |

## Appearance
- **Font**: Hack Nerd Font Mono, size 11
- **Theme**: Kanagawa Wave

## Installation

1. Ensure you have [Ghostty](https://ghostty.org/) installed (v1.3.1+).
2. Copy this directory to `~/.config/ghostty`.
3. Restart Ghostty — the config loads automatically.
