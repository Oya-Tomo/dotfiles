# Show Nix-installed apps in the GNOME start menu

> [!NOTE]
> This document was generated by Claude Code (Anthropic) based on debugging sessions and may contain inaccuracies.

On non-NixOS systems, applications installed via Home Manager may not appear in
the GNOME application menu when the Nix profile's data directories are missing
from `XDG_DATA_DIRS`.

## Solution

Add the following to your home-manager configuration:

```nix
targets.genericLinux.enable = true;
```

This option tells home-manager to apply compatibility settings for non-NixOS Linux distributions, including:

- Adding Nix profile paths to `XDG_DATA_DIRS` so `.desktop` files are discovered
- Adding the corresponding paths to `XDG_CONFIG_DIRS`
- Enabling other integration needed by Home Manager on non-NixOS Linux

## Where to put it

In the main home-manager module (e.g. `default.nix`):

```nix
{ config, pkgs, lib, ... }:

{
  imports = [
    ./packages.nix
    ./programs
    ./dotfiles.nix
  ];

  home.username = "your-username";
  home.homeDirectory = "/home/your-username";
  home.stateVersion = "25.05";

  programs.home-manager.enable = true;

  targets.genericLinux.enable = true;
}
```

## Verification

Apply the configuration:

```bash
nix run home-manager -- switch --flake ~/dotfiles
```

Then log out and log back in so the graphical session receives the updated
environment. Search for the application in the Activities overview.

Verify that the session contains the Nix profile data paths and that the profile
provides desktop entries:

```bash
printf '%s\n' "$XDG_DATA_DIRS" | tr ':' '\n'
find ~/.nix-profile/share/applications -maxdepth 1 -name '*.desktop' -print
```
