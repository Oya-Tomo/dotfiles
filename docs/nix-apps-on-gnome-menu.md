# Show Nix-installed apps in the GNOME start menu

> [!NOTE]
> This document was generated by Claude Code (Anthropic) based on debugging sessions and may contain inaccuracies.

On non-NixOS systems, applications installed via Nix home-manager do not appear in the GNOME application menu by default. This is because Nix-installed `.desktop` files are placed under `~/.local/share/applications/` without being indexed by the desktop environment.

## Solution

Add the following to your home-manager configuration:

```nix
targets.genericLinux.enable = true;
```

This option tells home-manager to apply compatibility settings for non-NixOS Linux distributions, including:

- Setting `XDG_DATA_DIRS` to include Nix profile paths so `.desktop` files are discovered
- Setting `XDG_CONFIG_DIRS` similarly
- Fixing other integration issues (icon themes, MIME type associations, etc.)

## Where to put it

In the main home-manager module (e.g. `default.nix`):

```nix
{ config, pkgs, lib, ... }:

{
  imports = [
    ./packages.nix
    ./programs
    ./dotfiles.nix
  ];

  home.username = "oyatomo";
  home.homeDirectory = "/home/oyatomo";
  home.stateVersion = "25.05";

  programs.home-manager.enable = true;

  targets.genericLinux.enable = true;
}
```

## Verification

After running `home-manager switch`, log out and log back in (or restart GNOME Shell with <kbd>Alt+F2</kbd> → `r`). Search for the app in the Activities overview.

You can verify the `.desktop` files are in the right place:

```bash
ls ~/.local/share/applications/*.desktop
```
