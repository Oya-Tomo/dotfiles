# Running WezTerm on non-NixOS (Nix + NVIDIA)

> [!NOTE]
> This document was generated by Claude Code (Anthropic) based on debugging sessions and may contain inaccuracies.

When installing WezTerm via Nix home-manager on a non-NixOS system, it fails to launch due to missing OpenGL/EGL libraries. Home-manager's `targets.genericLinux.gpu` module solves this by placing GPU drivers at `/run/opengl-driver`, where Nix binaries can find them via their RUNPATH. See the [official documentation](https://github.com/nix-community/home-manager/blob/master/docs/manual/usage/gpu-non-nixos.md) for full details.

## Environment

| Item | Value |
|---|---|
| OS | Ubuntu 24.04 (non-NixOS) |
| GPU | Intel Iris Xe (display output) + NVIDIA RTX 4050 (offload) |
| NVIDIA driver | 595.58.03 (proprietary) |
| Nix | flakes + home-manager (master) |
| Session | X11 (`XDG_SESSION_TYPE=x11`) |

## How it works

Nix packages that use GL (like WezTerm) link against libglvnd's `libEGL.so.1` and `libGLX.so.0`. These libraries have `/run/opengl-driver/lib` baked into their RUNPATH by nixpkgs' `addDriverRunpath` setup hook. On NixOS, `hardware.graphics.enable` creates this path; on non-NixOS, home-manager's `gpu` module does the same:

1. Builds a `buildEnv` containing Mesa, Intel media drivers, and optionally NVIDIA proprietary drivers
2. Creates a `tmpfiles.d` config that symlinks this environment to `/run/opengl-driver` on boot
3. libglvnd finds vendor JSONs at `/run/opengl-driver/share/glvnd/egl_vendor.d/` (compiled-in default search path)
4. libglvnd auto-selects the correct vendor: Mesa EGL for Intel display, NVIDIA EGL for NVIDIA display

No `LD_LIBRARY_PATH`, no `__EGL_VENDOR_LIBRARY_FILENAMES`, no wrapper scripts needed.

## Setup

### 1. Configure home-manager

In your home-manager configuration (e.g. `default.nix`):

```nix
{ config, pkgs, lib, ... }:

{
  # ...

  nixpkgs.config = {
    allowUnfree = true;
    nvidia.acceptLicense = true;
  };

  targets.genericLinux.enable = true;

  targets.genericLinux.gpu = {
    enable = true;
    nvidia = {
      enable = true;
      version = "595.58.03";
      sha256 = "sha256-jA1Plnt5MsSrVxQnKu6BAzkrCnAskq+lVRdtNiBYKfk=";
    };
  };
}
```

WezTerm uses the stock package — no wrapping needed:

```nix
{ config, pkgs, lib, ... }:

{
  programs.wezterm = {
    enable = true;
  };

  xdg.configFile."wezterm".source = ./../../../../wezterm;
}
```

### 2. Run the GPU setup script (one-time, requires sudo)

After `home-manager switch`, the activation script will warn you to run:

```bash
sudo /nix/store/HASH-non-nixos-gpu/bin/non-nixos-gpu-setup
```

This installs a `tmpfiles.d` config that creates `/run/opengl-driver` on every boot. You only need to re-run it when the driver version changes.

### 3. Get the NVIDIA driver hash

When upgrading the NVIDIA driver, update `version` and recalculate `sha256`:

```bash
nix store prefetch-file \
  https://download.nvidia.com/XFree86/Linux-x86_64/VERSION/NVIDIA-Linux-x86_64-VERSION.run
```

Replace `VERSION` with your exact driver version (appears twice in the URL).

## Verification

```bash
# Check /run/opengl-driver exists
ls -la /run/opengl-driver

# Verify vendor JSONs are present
ls /run/opengl-driver/share/glvnd/egl_vendor.d/

# Test WezTerm
wezterm
```

## Upgrading the NVIDIA driver

When the host system's NVIDIA driver is updated:

1. Get the new version: `nvidia-smi | head -2`
2. Get the new hash: `nix store prefetch-file https://download.nvidia.com/XFree86/Linux-x86_64/VERSION/NVIDIA-Linux-x86_64-VERSION.run`
3. Update `version` and `sha256` in your config
4. Run `home-manager switch`
5. Re-run `sudo .../non-nixos-gpu-setup` with the new path
