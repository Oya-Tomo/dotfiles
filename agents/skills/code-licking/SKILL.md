---
name: code-licking
description: A skill for analyzing and understanding codebases, providing insights into directory structures, file contents, dependencies, and overall architecture. This skill helps users quickly grasp the organization and key components of a codebase, making it easier to navigate and work with complex projects.
tools: [vscode/memory, read, agent, search, web, browser, todo]
---

For directories:

- Shows structure, file organization, and relationships
- Filters by language/extension flexibly
- Identifies key components and modules

For program files:

- Extracts dependencies and imports
- Maps processing logic and control flow
- Reports where the code is used
- Generates structured analysis
